# KAPO Custom Black 2.000

A display face rebuilt from the KAPO wordmark, not traced from the earlier broken font.

The wordmark K, A, and P set the design: stems are about 30% of the cap height, terminals are round, the A has an open crotch and a triangular counter, and the P bowl uses a wide pill counter. Lowercase bowls share one x-height and one counter size. Descenders are only the stem or the tail.

## Metrics

Units per em: 1000.

| Guide | Position |
| --- | --- |
| Typographic ascender | 800 |
| Ascender (b, d, f, h, k, l) | 768 |
| Cap height | 720 |
| x-height | 540 |
| Baseline | 0 |
| Descender ink | about -200 |
| Typographic descender | -250 |
| Uppercase stem | 214 |
| Lowercase stem | 166 |
| Round overshoot | 18 |

## Files

- `KAPO-Custom-Black.ttf` — TrueType, installable
- `KAPO-Custom-Black.otf` — CFF outlines of the same shapes
- `KAPO-Custom-Black.woff2` — webfont
- `KAPO-Custom-Black.sfd` — cubic source for FontForge
- `KAPO-Font-Specimen.png` — text rendered from the TTF
- `KAPO-Glyph-Metrics.png` — baseline, x-height, cap, ascender, descender
- `FONT-QA-REPORT.md` — automated checks and visual review

The geometry is generated by `scripts/build_kapo_font.py` in the website project.

## Characters

A–Z, a–z, 0–9, space, and `. , ! ? : ; ' " - _ / & @ # $ % + = ( ) [ ] { } *`

Digits are tabular.

## Website

The site loads the versioned files below. The previous `/fonts/KAPO-Custom-Black.woff2` and `.ttf` are still on disk and are no longer referenced.

Versioned copies for review are:

- `/fonts/KAPO-Custom-Black-v3.woff2`
- `/fonts/KAPO-Custom-Black-v3.ttf`

After review, point the existing family at the versioned files:

```css
@font-face {
  font-family: "KAPO Custom";
  src: url("/fonts/KAPO-Custom-Black-v3.woff2") format("woff2"),
       url("/fonts/KAPO-Custom-Black-v3.ttf") format("truetype");
  font-weight: 100 900;
  font-style: normal;
  font-display: swap;
}
```

Headings already use `font-family: var(--font-kapo)`, which is `"KAPO Custom"`. No other site content needs to change. The filename is versioned so browsers do not keep the previous file.
